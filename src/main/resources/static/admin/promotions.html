DISCOUNT STRATEGIES

Discount Types

NEXORA жүйесіндегі жеңілдіктердің екі түрі

PERCENTAGE

Percentage Discount

Себет сомасынан белгілі бір пайызды шегереді. Мысалы, 10% жеңілдік тауарлардың жалпы құнына пропорционалды есептеледі.

Мысал 50 000 ₸ − 10% = 45 000 ₸
FIXED

Fixed Amount Discount

Себет сомасынан нақты бекітілген ақша мөлшерін шегереді. Жеңілдік тапсырыс сомасынан аспайтындай есептеледі.

Мысал 50 000 ₸ − 5 000 ₸ = 45 000 ₸
IMPORTANT INFORMATION

Promotion Rules

01
Unique Promo Code

Әр промокод бірегей болуы керек. Кодты бас әріптермен енгіземіз.

02
Active / Inactive

Белсенді промокод Checkout кезінде қолданылуы мүмкін. Белсенді емес промокод жеңілдік бермейді.

03
Server-side Validation

Промокод пен жеңілдік сомасын Backend тексереді. Соңғы есептеуді сервер орындайды.
